# Deutscha Mod (Fabric, Minecraft 26.3, nur Client)

Features
- Dein eigener Name (Account-Name) wird überall als animierter Rainbow angezeigt (Tab, Chat, Schilder, Nametags)
- XP-Bar mit animiertem pink/lila Enchant-Effekt
- Splash-Texte auf dem Titelscreen: nur "ABONNIERE DEUTSCHA", "SUBSCRIBE TO DEUTSCHA", "DGH AUF DIE 1!"
- Blaues Totem mit grün/dunkelgrün und D
- Amboss: "&aLOL" tippen -> für dich grün, Server/andere sehen nur "LOL" (gespeichert in config/deutschamod/anvil_names.json)

Bauen (lokal): JDK 25, dann `./gradlew build` -> Jar in build/libs/deutscha-mod-1.0.0.jar
Bauen (ohne lokales Setup): Ordner als GitHub-Repo hochladen, Tab "Actions" -> Run -> Artifact "deutscha-mod" herunterladen
